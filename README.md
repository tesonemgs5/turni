# Calendario Turni

App per gestire turni di lavoro (web, Android, Windows). Demo web: https://turni-alpha.vercel.app

La documentazione, i piani e le regole di lavoro sono nel repo privato `note1977/note`, cartella `turni/` (indice: `turni/README.md`, regole: `turni/REGOLE-INVARIABILI.md`). Qui restano codice, test, workflow, script di build e i file `.sql`.

Database: nell'SQL Editor di Supabase si eseguono `schema.sql` e `colori.sql`; gli altri `.sql` solo se serve la funzione che descrivono.
